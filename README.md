# ⚡ SysForge — Tactical HUD Desktop OS & Jarvis AI

> **SysForge** — это полнофункциональная тактическая десктопная eDEX-UI «ОС»-оболочка для системных администраторов, DevOps, специалистов по кибербезопасности и разработчиков.
> Проект сочетает научно-фантастический HUD-интерфейс, живую аппаратную телеметрию, **31 полноценную мини-программу**, интерактивный фотореалистичный 3D-глобус Земли, голографический 3D Arc Reactor и автономного голосового ИИ-ассистента **Джарвиса (J.A.R.V.I.S.)**.
> Построена на стеке **React 18 + TypeScript + Vite 5 + Tauri 2 (Rust Tokio)**.

## ✨ Ключевые особенности

- ⚡ **Мгновенный отклик (0 ms Direct Execution)**: Популярные системные команды (запуск калькулятора, блокнота, проводника, диспетчера задач, браузеров Chrome/Edge/Firefox/Opera, терминала, поиск в Google) и закрытие любых запущенных процессов выполняются моментально локальным роутером без задержек LLM.
- 🤖 **Гибридный Мульти-провайдерный ИИ-пул**:
  - Поддержка **Google Gemini (gemini-3.6-flash / 2.0-flash)**, **Groq (Llama 3.3)**, **Mistral AI**, **OpenRouter**, **OpenAI** и локальной **Ollama**.
  - **Автоматический Fallback**: Мгновенный переход на резервного провайдера при исчерпании лимитов токенов (HTTP 429) или сетевых сбоях.
  - **Ollama Smart Auto-Discovery**: Автоматическое чтение установленных моделей (`/api/tags`) и привязка к `llama3:latest` / `gemma` с бесшовным извлечением действий.
  - **Персистентность и аппаратное шифрование ключей**: Все секретные API-ключи шифруются по алгоритму **AES-256-GCM** с привязкой к MachineGuid материнской платы.
- 🌐 **Центральный интерактивный 3D Глобус (Three.js)**:
  - Реальная текстурная карта Земли (NASA Blue Marble) с ночными огнями мегаполисов, тактической сеткой координат и атмосферным гало.
  - 30+ реальных мировых узлов связи (Москва, Ташкент, Нью-Йорк, Токио, Лондон, Сингапур и др.) со световыми маяками и динамическими дугами кибер-трафика.
  - 8 орбитальных спутников на рассчитанных неклипующих траекториях со световыми шлейфами.
  - **Реакция на голос Джарвиса**: сфера дышит, увеличивается при разговоре и меняет свечение в зависимости от фазы диалога (`speaking`, `listening`, `thinking`).
- 🔮 **Голографический 3D Arc Reactor**: Трёхмерная голограмма в стиле реактора Тони Старка с геодезической триангулированной сферой, турбинными блоками и волновой вуалью из 2000 светящихся частиц.
- 🎙️ **Голос Джарвиса (Офлайн TTS + STT)**: Синтез речи на системных оффлайн-голосах (Microsoft Pavel / David / Irina) с кинематографичным тембром, живым эквалайзером громкости звука и VAD (детектором активности речи).
- 🔲 **Toggle-управление окнами**: Одно нажатие на приложение в боковой панели открывает его, повторное нажатие — закрывает. Окна свободно перетаскиваются и масштабируются.
- 📊 **Телеметрия в реальном времени**: Мониторинг ядер CPU, оперативной памяти, дисковых накопителей, сетевого трафика (включая UDP/QUIC соединения Google Chrome и delta I/O).

## 🤖 Голосовой ИИ-ассистент «Джарвис» (Jarvis 2.0)

Джарвис глубоко интегрирован в операционную оболочку SysForge и выполняет роль персонального тактического помощника:

```
 Пользователь (Голос / Текст)
       │
       ▼
 0. Очистка обращений ("Джарвис, открой...")
       │
       ├─► 1. Direct Execution Match (70+ паттернов) ──► Мгновенное выполнение (0 ms)
       │
       ├─► 2. ONNX Embedding / Keyword Match ──────────► Выполнение сохранённого навыка
       │
       └─► 3. LLM Orchestrator (Multi-Provider Pool)
                 │
                 ├── 1st: Активный провайдер (Gemini / Groq / Ollama / Mistral)
                 └── Fallback: Авто-переход на резервный провайдер при 429 / ошибке
```

### Возможности Джарвиса:

1. **Прямое управление Windows и приложениями SysForge**:
   - *«Джарвис, открой калькулятор»* ➔ запускает `calc.exe`.
   - *«Открой блокнот»* ➔ запускает `notepad.exe`.
   - *«Открой проводник»* ➔ запускает `explorer.exe`.
   - *«Диспетчер задач»* ➔ открывает `taskmgr.exe`.
   - *«Открой браузер / Chrome / Edge»* ➔ открывает выбранный браузер.
   - *«Открой терминал»*, *«Открой автозагрузку»*, *«Анализ диска»*, *«Поиск дубликатов»*, *«Проводник файлов»*.
   - *«Закрой блокнот»*, *«Закрой калькулятор»*, *«Закрой хром»*, *«Закрой [имя процесса]»* ➔ безопасное завершение через системный процесс-киллер с реальным отчётом об остановке процесса.
   - *«Открой YouTube»*, *«Гитхаб»*, *«Википедию»* ➔ открывает в браузере.
   - *«Поищи документацию React»* ➔ запускает поиск в Google.
2. **Голосовой ввод с живым эквалайзером**:
   - Прямой захват через `AudioRecorder` (Web Audio API).
   - Живой неоновый индикатор уровня сигнала микрофона (`🎤 Слушаю... ██████░░░░`).
   - Встроенный детектор активности речи (VAD) с автоматическим завершением фразы.
   - Whisper STT (Groq / OpenAI) как сверхбыстрый фоллбэк.
3. **Диалоговая память (Multi-turn Session Context)**:
   - Хранит историю сообщений и выполненных действий.
   - Помнит контекст: можно спросить *«Что ты только что открыл?»* или *«Повтори»*.
   - Кнопка `🧹` в заголовке чата для быстрой очистки сессии.
4. **Перетаскиваемый интерфейс чата (Draggable Window)**:
   - Окно чата свободно перетаскивается за верхнюю панель в любую область экрана без блокировки фоновых элементов.

## 🛡️ Аппаратное шифрование API-ключей (AES-256-GCM)

Все конфиденциальные данные пользователя (ключи Gemini, Groq, Mistral, OpenRouter, OpenAI, AbuseIPDB, VirusTotal, NVD) защищены сквозным аппаратным шифрованием:
- **Алгоритм**: `AES-256-GCM` с генерацией случайного 96-битного `nonce` на каждую операцию шифрования.
- **Деривация мастер-ключа**: Ключ деривируется с помощью `SHA-256` из аппаратного идентификатора системы `Cryptography\MachineGuid` в реестре Windows.
- **Префиксная защита (`enc:aes256:`)**: Приложение безошибочно разделяет открытые и зашифрованные данные, гарантируя, что даже при ошибках дешифрования ключи никогда не стираются в пустую строку при перезапуске.

## 🛡️ Безопасность и Rust Backend

1. **Защита от RCE и строгий Whitelist**:
   - В командах управления процессами устранён шелл-парсинг: запуск и закрытие программ производятся строго через Windows API без опасных вызовов `cmd /c`.
2. **Асинхронный Tokio рантайм**:
   - Все тяжелые операции (`ping`, `traceroute`, `sysinfo`, анализ дисков, сканирование дубликатов) выполняются в отдельных потоках с жесткими таймаутами.
3. **Скрытые консольные окна (`CREATE_NO_WINDOW`)**:
   - Системные команды не создают мигающих черных окон консоли на экране пользователя.
4. **Безопасная санитизация аргументов**:
   - Защита от Command Injection: все IP-адреса, хосты и пути файлов проходят строгую валидацию.
5. **Универсальный LLM HTTP-прокси**:
   - Команда `jarvis_llm_request` обходит ограничения CORS в десктопном окружении и обеспечивает бесперебойную связь с любыми нейросетями.

## 🚀 Установка и запуск

### Требования к системе
- **Node.js** 18.0 или новее
- **Rust** (Cargo) 1.75+ (для десктопной сборки Tauri)

### 1. Установка зависимостей
```bash
git clone https://github.com/Komr0n/SysForge.git
cd SysForge
npm install
```

### 2. Запуск в режиме Web (быстрый предпросмотр в браузере)
```bash
npm run dev
```
Откройте в браузере: `http://localhost:1420`

### 3. Запуск в десктопном режиме Tauri (полный доступ к системным API)
```bash
npm run tauri dev
```

### 4. Продакшн-сборка
```bash
npm run build
```
Для сборки готового `.exe` инсталлятора Windows:
```bash
npm run tauri build
```
