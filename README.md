# ⚡ SysForge — Tactical HUD Desktop OS & Jarvis AI

> **SysForge** — это полнофункциональная тактическая десктопная eDEX-UI «ОС»-оболочка для системных администраторов, DevOps, специалистов по кибербезопасности и разработчиков.
> Проект сочетает научно-фантастический HUD-интерфейс, живую аппаратную телеметрию, 24 полноценные мини-программы, интерактивный 3D-глобус Земли и автономного голосового ИИ-ассистента **Джарвиса (J.A.R.V.I.S.)**.
> Построена на стеке **React 18 + TypeScript + Vite 5 + Tauri 2 (Rust Tokio)**.

## ✨ Ключевые особенности

- ⚡ **Мгновенный отклик (0 ms Direct Execution)**: Простые системные команды (запуск калькулятора, блокнота, проводника, диспетчера задач, поиск в Google) выполняются моментально без задержек и без обращения к нейросетям.
- 🤖 **Мульти-провайдерный ИИ-пул**: Поддержка Google Gemini, Groq (Llama 3.3), Mistral AI, OpenRouter, OpenAI и локальной Ollama с автоматическим переключением (Auto-Fallback) при исчерпании лимитов токенов (HTTP 429).
- 🎙️ **Голос Джарвиса из Marvel (Офлайн TTS + STT)**: Синтез речи на системных оффлайн-голосах (Microsoft Pavel / David) с кинематографичным тембром, живым эквалайзером громкости звука и Whisper-транскрипцией.
- 🌐 **Интерактивный 3D Глобус**: Процедурный WebGL-глобус Земли с вращением мышью, зумом, атмосферой и анимированными орбитальными спутниками.
- 🔲 **Toggle-управление окнами**: Одно нажатие на приложение в боковой панели открывает его, повторное нажатие — закрывает.
- 📊 **Телеметрия в реальном времени**: Мониторинг ядер CPU, оперативной памяти, дисковых накопителей, сетевого трафика (Rx/Tx) и интерактивный MiniTerminal.

## 🤖 Голосовой ИИ-ассистент «Джарвис» (Jarvis 2.0)

Джарвис глубоко интегрирован в операционную оболочку SysForge и выполняет роль персонального тактического помощника:

```
 Пользователь (Голос / Текст)
       │
       ▼
 0. Очистка обращений ("Джарвис, открой...")
       │
       ├─► 1. Direct Execution Match (50+ паттернов) ──► Мгновенное выполнение (0 ms)
       │
       ├─► 2. ONNX Embedding / Keyword Match ──────────► Выполнение сохранённого навыка
       │
       └─► 3. LLM Orchestrator (Multi-Provider Pool)
                 │
                 ├── 1st: Активный провайдер (Gemini / Groq / Ollama / Mistral)
                 └── Fallback: Авто-переход на резервный провайдер при 429 / ошибке
```

### Возможности Джарвиса:
1. **Прямое управление Windows и SysForge**:
   - *«Джарвис, открой калькулятор»* ➔ запускает `calc.exe`.
   - *«Открой блокнот»* ➔ запускает `notepad.exe`.
   - *«Открой проводник»* ➔ запускает `explorer.exe`.
   - *«Диспетчер задач»* ➔ открывает `taskmgr.exe`.
   - *«Открой YouTube»*, *«Гитхаб»*, *«Википедию»* ➔ открывает в браузере.
   - *«Поищи документацию React»* ➔ запускает поиск в Google.
   - *«Открой пинг»*, *«Покажи процессы»*, *«Смени тему на dark»*, *«Включи матрицу»*.
2. **Голосовой ввод с живым эквалайзером**:
   - Прямой захват через `AudioRecorder` (Web Audio API).
   - Живой неоновый индикатор уровня сигнала микрофона (`🎤 Слушаю... ██████░░░░`).
   - Встроенный детектор активности речи (VAD) с автоматическим завершением фразы.
   - Whisper STT (Groq / OpenAI) как сверхбыстрый фоллбэк.
3. **Диалоговая память (Multi-turn Session Context)**:
   - Хранит историю последних 20 сообщений и выполненных действий.
   - Помнит контекст: можно спросить *«Что ты только что открыл?»* или *«Повтори»*.
   - Кнопка `🧹` в заголовке чата для быстрой очистки сессии.
4. **Самообучение и визуальный редактор навыков (Skill Creator)**:
   - После выполнения сложных цепочек действий Джарвис предлагает сохранить сценарий в один клик.
   - Навыки сохраняются в локальный реестр с гибкой настройкой слотов параметров.
5. **Безопасный Sandbox**:
   - 3 уровня разрешений: `Minimal` (UI), `Standard` (Read-only системная инфо), `Full` (деструктивные операции с модальным окном подтверждения).

## 🖥️ Архитектура интерфейса (HUD Layout)

Интерфейс спроектирован по канонам тактических HUD-систем:

- **StatusBar (Верхняя панель, 38px)**:
  - Логотип `SYSFORGE HUD v1.0`.
  - Монитор нагрузки CPU% и RAM%.
  - Индикатор состояния Джарвиса (`IDLE` ➔ `LISTENING` ➔ `THINKING` ➔ `EXECUTING` ➔ `SPEAKING`).
  - Кнопка быстрого голосового ввода 🎤 (сразу открывает чат и активирует микрофон).
  - Кнопка настроек ИИ-провайдеров ⚙️.
  - Полноэкранный режим (F11) и системные часы.
- **Sidebar (Левая панель, 220px / 48px)**:
  - 4 категории: `Network`, `Security`, `System`, `Developer`.
  - 24 приложения с поддержкой **Toggle** (клик открывает / повторный клик закрывает) и неоновой подсветкой активных окон.
- **Workspace (Центральная рабочая область)**:
  - Перетаскиваемые и масштабируемые окна приложений на базе `react-rnd`.
  - Оверлейные виджеты: большие часы `ClockWidget` и 3D-глобус Земли.
- **SideRail (Правая панель инструментов, 256px)**:
  - **3D Globe Widget**: Интерактивная трёхмерная Земля с вращением, атмосферой и спутниками.
  - **Network Monitor**: График реального входящего и исходящего трафика (Rx/Tx bytes/sec).
  - **Audio Visualizer**: Частотный спектральный анализатор звука.
- **TelemetryBar (Нижняя телеметрическая панель)**:
  - **System Vitals**: Концентрические HUD-кольца CPU / RAM / Диск / FPS.
  - **MiniTerminal**: Встроенная интерактивная консоль для выполнения системных команд.
- **Taskbar (Нижняя панель задач, 28px)**:
  - Список свернутых и активных окон с переключением фокуса в один клик.

## 🛡️ Безопасность и Rust Backend

1. **Асинхронный Tokio рантайм**:
   - Все тяжелые операции (`ping`, `traceroute`, `sysinfo`) выполняются через `tokio::task::spawn_blocking` с жесткими таймаутами.
2. **Скрытые консольные окна (`CREATE_NO_WINDOW`)**:
   - Системные команды не создают мигающих черных окон консоли на экране пользователя.
3. **Безопасная санитизация аргументов**:
   - Защита от Command Injection: все IP-адреса и хосты проходят строгую валидацию перед вызовом системных утилит.
4. **Native Application Spawner**:
   - Команда `jarvis_open_system_app` безопасно и отвязанно запускает программы ОС (calc, notepad, explorer).

## 🚀 Установка и запуск

### Требования к системе
- **Node.js** 18.0 или новее
- **Rust** (Cargo) 1.75+ (для десктопной сборки Tauri)

### 1. Установка зависимостей
```bash
cd sysforge
npm install
```

### 2. Запуск в режиме Web (быстрый предпросмотр в браузере)
```bash
npm run dev
```
Откройте в браузере: `http://localhost:1420`

### 3. Запуск в десктопном режиме Tauri (полный доступ к системным API)
```bash
npm run tauri dev
```

### 4. Продакшн-сборка
```bash
npm run build
```
Для сборки готового `.exe` инсталлятора Windows:
```bash
npm run tauri build
```
