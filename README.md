# ⚡ SysForge — Tactical HUD Desktop OS & Jarvis AI

> **SysForge** — это полнофункциональная тактическая десктопная eDEX-UI «ОС»-оболочка для системных администраторов, DevOps, специалистов по кибербезопасности и разработчиков.
> Проект сочетает научно-фантастический HUD-интерфейс, живую аппаратную телеметрию, 26 полноценных мини-программ, интерактивный 3D-глобус Земли, голографический 3D Arc Reactor и автономного голосового ИИ-ассистента **Джарвиса (J.A.R.V.I.S.)**.
> Построена на стеке **React 18 + TypeScript + Vite 5 + Tauri 2 (Rust Tokio)**.

## ✨ Ключевые особенности

- ⚡ **Мгновенный отклик (0 ms Direct Execution)**: Популярные системные команды (запуск калькулятора, блокнота, проводника, диспетчера задач, браузера, поиск в Google) выполняются моментально локальным роутером без обращения к LLM.
- 🤖 **Гибридный Мульти-провайдерный ИИ-пул**:
  - Поддержка **Google Gemini**, **Groq (Llama 3.3)**, **Mistral AI**, **OpenRouter**, **OpenAI** и локальной **Ollama**.
  - **Автоматический Fallback**: Мгновенный переход на резервного провайдера при исчерпании лимитов токенов (HTTP 429) или сетевых сбоях.
  - **Ollama Smart Text-Mode**: Автоматическая адаптация локальных моделей без поддержки нативных OpenAI Tools (`llama3:latest`, `gemma4:12b` и др.) с бесшовным извлечением действий.
  - **Персистентность настроек**: Надёжное сохранение всех введённых API-ключей и профилей между перезапусками приложения.
- 🔮 **Голографический 3D Arc Reactor (Three.js)**: Центральная трёхмерная голограмма в стиле реактора Тони Старка с геодезической триангулированной сферой, вращающимися сегментированными блоками и органической волновой вуалью из 2000 светящихся частиц.
- 🎙️ **Голос Джарвиса из Marvel (Офлайн TTS + STT)**: Синтез речи на системных оффлайн-голосах (Microsoft Pavel / David) с кинематографичным тембром, живым эквалайзером громкости звука и VAD (детектором активности речи).
- 🌐 **Интерактивный 3D Глобус**: Процедурный WebGL-глобус Земли с вращением мышью, зумом, атмосферой и анимированными орбитальными спутниками.
- 🔲 **Toggle-управление окнами**: Одно нажатие на приложение в боковой панели открывает его, повторное нажатие — закрывает. Окна свободно перетаскиваются и масштабируются.
- 📊 **Телеметрия в реальном времени**: Мониторинг ядер CPU, оперативной памяти, дисковых накопителей, сетевого трафика (Rx/Tx bytes/sec) и интерактивный MiniTerminal.

## 🤖 Голосовой ИИ-ассистент «Джарвис» (Jarvis 2.0)

Джарвис глубоко интегрирован в операционную оболочку SysForge и выполняет роль персонального тактического помощника:

```
 Пользователь (Голос / Текст)
       │
       ▼
 0. Очистка обращений ("Джарвис, открой...")
       │
       ├─► 1. Direct Execution Match (50+ паттернов) ──► Мгновенное выполнение (0 ms)
       │
       ├─► 2. ONNX Embedding / Keyword Match ──────────► Выполнение сохранённого навыка
       │
       └─► 3. LLM Orchestrator (Multi-Provider Pool)
                 │
                 ├── 1st: Активный провайдер (Gemini / Groq / Ollama / Mistral)
                 └── Fallback: Авто-переход на резервный провайдер при 429 / ошибке
```

### Возможности Джарвиса:

1. **Прямое управление Windows и SysForge**:
   - *«Джарвис, открой калькулятор»* ➔ запускает `calc.exe`.
   - *«Открой блокнот»* ➔ запускает `notepad.exe`.
   - *«Открой проводник»* ➔ запускает `explorer.exe`.
   - *«Диспетчер задач»* ➔ открывает `taskmgr.exe`.
   - *«Закрой блокнот»*, *«Закрой калькулятор»* ➔ безопасное завершение через системный процесс-киллер.
   - *«Открой YouTube»*, *«Гитхаб»*, *«Википедию»* ➔ открывает в браузере.
   - *«Поищи документацию React»* ➔ запускает поиск в Google.
   - *«Открой пинг»*, *«Покажи процессы»*, *«Смени тему на dark»*, *«Включи матрицу»*.
2. **Голосовой ввод с живым эквалайзером**:
   - Прямой захват через `AudioRecorder` (Web Audio API).
   - Живой неоновый индикатор уровня сигнала микрофона (`🎤 Слушаю... ██████░░░░`).
   - Встроенный детектор активности речи (VAD) с автоматическим завершением фразы.
   - Whisper STT (Groq / OpenAI) как сверхбыстрый фоллбэк.
3. **Диалоговая память (Multi-turn Session Context)**:
   - Хранит историю последних 20 сообщений и выполненных действий.
   - Помнит контекст: можно спросить *«Что ты только что открыл?»* или *«Повтори»*.
   - Кнопка `🧹` в заголовке чата для быстрой очистки сессии.
4. **Перетаскиваемый интерфейс чата (Draggable Window)**:
   - Окно чата свободно перетаскивается за верхнюю панель в любую область экрана без блокировки фоновых элементов.
5. **Журнал аудита действий (Audit Log)**:
   - Кнопка `📋` в верхней панели для просмотра полного хронологического журнала действий: название инструмента, аргументы, источник команды и статус выполнения.
6. **Самообучение и визуальный редактор навыков (Skill Creator)**:
   - После выполнения сложных цепочек действий Джарвис предлагает сохранить сценарий в один клик.
   - Навыки сохраняются в локальный реестр с гибкой настройкой слотов параметров.
7. **Безопасный Sandbox**:
   - 3 уровня разрешений: `Minimal` (UI), `Standard` (Read-only системная инфо), `Full` (деструктивные операции с модальным окном подтверждения).

## 🔮 Голографический 3D Arc Reactor HUD

В центре рабочего пространства расположен анимированный 3D-реактор на базе **Three.js**, визуализирующий активность Джарвиса:

- **Geodesic Wireframe Core**: Трёхмерная геодезическая икосаэдрическая сфера с чёткой геометрической триангуляцией и затемнённым внутренним ядром объёма.
- **Silhouette Rim**: Двойной яркий светящийся контур силуэта с эффектом аддитивного свечения (`AdditiveBlending`).
- **Segmented Turbine Dial**: Процедурно сгенерированное кольцо с 36 радиальными энергоблоками реактора, круговыми тикерами делений и техническими дорожками.
- **Organic Wave Curtain**: Волновое поле из 2000 частиц, плавно колеблющееся в реальном времени по синусоидальным гармоникам, образуя живую световую рябь вокруг реактора.
- **Динамическая адаптация под состояние**:
  - `idle`: Кибернетический бирюзово-циановый неоновый свет (`#00f0ff`).
  - `speaking`: Яркий янтарно-золотой свет с усиленной пульсацией волновых частиц.
  - `thinking`: Мистический фиолетово-пурпурный импульс.
  - `listening`: Насыщенный аквамариновый цвет.

## 🖥️ Архитектура интерфейса (HUD Layout)

Интерфейс спроектирован по канонам тактических HUD-систем:

- **StatusBar (Верхняя панель, 38px)**:
  - Логотип `SYSFORGE HUD v1.0`.
  - Монитор нагрузки CPU% и RAM%.
  - Индикатор состояния Джарвиса (`IDLE` ➔ `LISTENING` ➔ `THINKING` ➔ `EXECUTING` ➔ `SPEAKING`).
  - Кнопка быстрого голосового ввода 🎤 (сразу открывает чат и активирует микрофон).
  - Кнопка журнала аудита 📋 и настроек ИИ-провайдеров ⚙️.
  - Полноэкранный режим (F11) и системные часы.
- **Sidebar (Левая панель, 220px / 48px)**:
  - 4 категории: `Network`, `Security`, `System`, `Developer`.
  - 26 приложений с поддержкой **Toggle** (клик открывает / повторный клик закрывает) и неоновой подсветкой активных окон.
- **Workspace (Центральная рабочая область)**:
  - Перетаскиваемые и масштабируемые окна приложений на базе `react-rnd`.
  - Оверлейные виджеты: большие часы `ClockWidget`, голографический 3D Arc Reactor и 3D-глобус Земли.
- **SideRail (Правая панель инструментов, 256px)**:
  - **3D Globe Widget**: Интерактивная трёхмерная Земля с вращением, атмосферой и спутниками.
  - **Network Monitor**: График реального входящего и исходящего трафика (Rx/Tx bytes/sec).
  - **Audio Visualizer**: Частотный спектральный анализатор звука.
- **TelemetryBar (Нижняя телеметрическая панель)**:
  - **System Vitals**: Концентрические HUD-кольца CPU / RAM / Диск / FPS.
  - **MiniTerminal**: Встроенная интерактивная консоль для выполнения системных команд.
- **Taskbar (Нижняя панель задач, 28px)**:
  - Список свёрнутых и активных окон с переключением фокуса в один клик.

## 🛡️ Безопасность и Rust Backend

1. **Защита от RCE и строгий Whitelist**:
   - В команде `jarvis_open_system_app` устранён шелл-парсинг: имена программ проверяются по строгому белому списку системных исполняемых файлов (`calc`, `notepad`, `explorer`, `taskmgr`, `cmd`, `powershell`, `regedit`, `msedge`, `chrome` и др.) и запускаются напрямую без промежуточного вызова `cmd /c`.
2. **Асинхронный Tokio рантайм**:
   - Все тяжелые операции (`ping`, `traceroute`, `sysinfo`, `kill_process`) выполняются через `tokio::task::spawn_blocking` с жесткими таймаутами.
3. **Скрытые консольные окна (`CREATE_NO_WINDOW`)**:
   - Системные команды не создают мигающих черных окон консоли на экране пользователя.
4. **Безопасная санитизация аргументов**:
   - Защита от Command Injection: все IP-адреса, хосты и идентификаторы процессов проходят строгую валидацию перед вызовом системных утилит.
5. **Универсальный LLM HTTP-прокси**:
   - Команда `jarvis_llm_request` поддерживает методы `GET` и `POST`, позволяет обходить CORS в десктопном окружении и возвращает прозрачные диагностические сообщения при сбоях внешних API.

## 🚀 Установка и запуск

### Требования к системе
- **Node.js** 18.0 или новее
- **Rust** (Cargo) 1.75+ (для десктопной сборки Tauri)

### 1. Установка зависимостей
```bash
git clone https://github.com/Komr0n/SysForge.git
cd SysForge
npm install
```

### 2. Запуск в режиме Web (быстрый предпросмотр в браузере)
```bash
npm run dev
```
Откройте в браузере: `http://localhost:1420`

### 3. Запуск в десктопном режиме Tauri (полный доступ к системным API)
```bash
npm run tauri dev
```

### 4. Продакшн-сборка
```bash
npm run build
```
Для сборки готового `.exe` инсталлятора Windows:
```bash
npm run tauri build
```
